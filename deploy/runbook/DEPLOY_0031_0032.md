Paste the entire contents of `0031_subscription_change_log.sql` and run.

### Verify 0031 (read-only)

```sql
select 'subscription_changes exists'      as check, exists(select 1 from pg_class where relname='subscription_changes')::text as result
union all select 'policies in public (expect 106)', count(*)::text from pg_policies where schemaname='public'
union all select 'authenticated grants (expect SELECT)',
       coalesce(string_agg(privilege_type,',' order by privilege_type),'none')
  from information_schema.role_table_grants
 where table_name='subscription_changes' and grantee='authenticated'
union all select 'rows in the log (expect 0)', count(*)::text from subscription_changes;
```

**STOP if** the table is missing, policies ≠ 106, `authenticated` holds anything
other than `SELECT`, or the log is not empty.

### Verify 0032 (read-only)

```sql
select 'gated WRITE policies (expect 69)' as check, count(*)::text as result
  from pg_policies where schemaname='public'
   and coalesce(qual,'')||coalesce(with_check,'') like '%fn_account_is_entitled%'
union all select 'gated READ policies (expect 0)', count(*)::text
  from pg_policies where schemaname='public' and cmd='SELECT'
   and coalesce(qual,'')||coalesce(with_check,'') like '%fn_account_is_entitled%'
union all select 'total policies in public (expect 116)', count(*)::text
  from pg_policies where schemaname='public'
union all select 'payment failure grace (expect 7 days)', fn_payment_failure_grace()::text
union all select 'boundary constraint present', exists(
    select 1 from pg_constraint where conname='ck_subscriptions_period_present')::text
union all select 'fn_my_entitlement_status exists', exists(
    select 1 from pg_proc where proname='fn_my_entitlement_status')::text
union all select 'cost tables split into per-verb policies (expect 12)', count(*)::text
  from pg_policies where schemaname='public'
   and tablename in ('ingredient_prices','cost_snapshots','recipe_prices')
union all select 'entitlement fn reads the grace config', (
    select (pg_get_functiondef(oid) like '%fn_payment_failure_grace()%')::text
      from pg_proc where proname='fn_account_is_entitled');
```

**STOP if any value differs.** Do not improvise a repair.
