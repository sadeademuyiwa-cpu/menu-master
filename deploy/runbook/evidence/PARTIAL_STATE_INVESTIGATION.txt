   No hidden COMMIT exists in the file: stripping dollar-quoted bodies, comments

   MY ERROR. Every atomicity rehearsal used psql on one connection, where
   begin; genuinely opens a transaction. I proved the file atomic under psql and
   reported it as atomic under the Supabase SQL Editor, which is not the same
   claim. This is the third environment-fidelity gap in this deployment, and the
   first in the execution harness rather than the schema.

3. HOW FAR 0048 GOT
   0048 runs in four parts: a preflight assertion, the revoke loop, seven GRANT
   statements, then the self-check. The reported error came from the self-check,
   which is the LAST part and changes nothing. So the revokes and grants landed.

   A replica built as "0047, then 0048 truncated immediately before its
   self-check" is BYTE-IDENTICAL to a complete 0048 across the full schema
   fingerprint -- columns, function bodies, view definitions and reloptions,
   grants, policies, triggers, constraints and composite types (2444 lines).
   There is no difference between "0048 whose self-check aborted" and "0048".
